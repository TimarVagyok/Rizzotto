RizzOtto  · Quadruped Walking Firmware — Architecture

ESP32 · ESP-IDF (C) · 8× micro-servos (4 legs × hip+knee)
Pipeline: boot → mode → routine → gait → kinematics → PWM → servos
1 BOOT & INIT main.c · app_main()
ESP32 reset → app_main()
ledc_timer_config()50 Hz · 14-bit · TIMER_0 · high-speed
8× ledc_channel_config()GPIO ↔ CH0–CH7, all init to 90°
enter while(1) main loop
2 MAIN LOOP #define MODE
while(1) — compile-time MODEone firmware, switch behaviour
MODE 0 · runStandPose()hold calibrated stand
MODE 1 · testLeg(0..3)per-leg direction bring-up
MODE 2 · routinewalk → rotate, repeat
3 ROUTINES rizzotto_poses.h
walkForwardMeters(m)gHipSign = HIP_FWD → straight
rotateInPlace()gHipSign = HIP_ROT → spin
sitDown() · frontPawWave()pose moves (parked)
testLeg()exercise one leg for tuning
4 GAIT PRIMITIVES
walkForwardOneStep()trotHalfStep(0) + trotHalfStep(1)
trotHalfStep(g)lift diagonal pair → swing fwd + stroke other back → plant
standAndSettle()sync state to calibrated stand
moveAllTo()static poses (sit / wave)
5 MOTION CORE kinematics
state: gSwing[4], gLift[4], gHipSign−1 back · 0 stand · +1 fwd / lift
hipTarget()HIP_STAND + sign·swing·HIP_SWING
kneeTarget()KNEE_STAND + KNEE_UP·lift·KNEE_LIFT
applyTargets(ms)interpolate 8 servos in 15 ms steps
6 SERVO DRIVER → HW
set_servo_angle(i, °)clamp 0–180°
angle_to_duty()0–180° → 500–2500 µs pulse
ledc_set_duty + update_duty
LEDC PWM 50 Hz → 8 servos4 legs × (hip + knee)
CALIBRATION & TUNING Per-servo data feeding the Motion Core ▲ — set on hardware
HIP_IDX / KNEE_IDXleg → physical servo map
HIP_STAND / KNEE_STANDneutral “stand” angles per servo
DIAG pairs{FL,BR} & {FR,BL} trot diagonals
HIP_FWD {−1,−1,+1,+1}straight: front opposite back
HIP_ROT {+1,+1,+1,+1}spin: all hips same sense
KNEE_UPper-leg lift direction signs
HIP_SWING 26 · KNEE_LIFT 36stride length · foot clearance (°)
SWING_MS 110 · LIFT_MS 45move timing — smaller = faster
CYCLES_PER_METER 14 · TURN_CYCLES 8distance · rotation amount
