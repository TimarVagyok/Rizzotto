# 🤖 Project Rizzotto: The 4-Legged Otto Robot

Project **Rizzotto** transforms the famous cubic Otto DIY robot into an insect-inspired, 4-legged quadruped walker. 

---

## ⚙️ Features
* **Insect-Inspired:** 4-legged design engineered for stable, crawling gaits.
* **8-Servo Setup:** Utilizes 2 servos per leg (hip and knee) for dynamic range of motion.
* **100% 3D Printable:** All structural components and joints are designed to be printed at home with no extra hardware needed for the chassis.

## 🛠️ Hardware Requirements
* **Servos:** 8x Micro Servos SG90.
* **Controller:** Arduino Nano / ESP32 or compatible board.
* **Print Settings:** PLA/PETG, 20% infill, no supports needed for most parts.
